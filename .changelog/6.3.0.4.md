# QuickShop-Hikari 6.3.0.4

This release focuses on security, stability, Minecraft version compatibility, and improvements to third-party plugin integrations.

## Major Changes

- **Security: Patched a shop trading exploit** (#2597)
- Fixed ProtocolLib compatibility issues affecting virtual shop displays on Minecraft 1.21.10, 1.21.11, and 26.x, including chunk packet handling errors. (#2568, #2579, #2591)
- Fixed an issue where shop displays could fail to render when the economy provider had not finished initializing during server startup. (#2589)

## Minor Changes

- Restored ExcellentCrates compatibility in the MatcherPlus module. (#2583)
- **MatcherPlus compatibility module now requires Java 25.** Server owners using this optional module must ensure their environment supports Java 25. (#2597)
- Improved ProtocolLib chunk coordinate handling across different Minecraft versions, preventing `FieldAccessException` errors when processing chunk packets. (#2591)
- Added startup logging to identify whether ProtocolLib or PacketEvents is being used for virtual shop displays. (#2591)
- Updated plugin permission declarations and compatibility plugin metadata. (#2579)
- Improved economy formatting fallback behavior when an economy provider is temporarily unavailable. (#2589)
- Updated German, Spanish, Turkish, Bulgarian, and Traditional Chinese translations through Crowdin. (#2569, #2570, #2574, #2575, #2577, #2582)
- Updated the bug report template to include an AI-generated content disclosure. (#2588)

## Important Notes

- **Security update:** Server owners are strongly encouraged to upgrade to 6.3.0.4 to receive the latest shop trading security fixes.
- **Java 25 requirement:** The MatcherPlus compatibility module requires Java 25. This requirement applies to MatcherPlus and should not be interpreted as a new Java 25 requirement for the entire QuickShop-Hikari plugin.
